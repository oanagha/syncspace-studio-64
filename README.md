# SyncSpace Collaborative Hub

Design a premium, futuristic, and highly polished full-stack SaaS frontend called “SyncSpace” — a real-time collaborative workspace for teams, freelancers, and startups. The UI should feel like a mix of Notion, Linear, ClickUp, and Arc Browser, but with a unique and memorable visual identity. Do NOT use a dark theme. Use a modern light theme with a beautiful color palette: - Primary: #6C63FF (soft indigo) - Secondary: #8B5CF6 (violet) - Accent: #06B6D4 (cyan) - Success: #10B981 - Warning: #F59E0B - Surface: #FFFFFF - Background: #F6F8FC - Soft gradients: indigo → violet → cyan Typography: - Use Inter or Plus Jakarta Sans. - Large bold headings, spacious layout, generous white space. - Rounded corners (20–28px), soft shadows, glassmorphism where appropriate. Create a complete multi-page SaaS frontend with responsive desktop, tablet, and mobile layouts. Pages and features to include: 1. Landing Page - Sticky glassmorphism navbar - Logo + SyncSpace - Links: Features, Pricing, About, Contact - CTA buttons: Get Started / Live Demo - Hero section with animated workspace mockup - Floating cards and parallax effects on scroll - Team avatars, task cards, and notification previews - Trusted by startups section - Feature showcase with alternating layouts - Real-time collaboration illustration - Analytics and productivity section - Testimonials - Pricing cards - FAQ accordion - Modern footer 2. Authentication - Sign In - Sign Up - Forgot Password - Split-screen layout with animated illustration - Social login buttons - Smooth form transitions 3. Main App Layout - Collapsible sidebar - Workspace switcher - Search command bar (Ctrl+K) - Top navigation with notifications, activity, and profile - Floating quick-create button 4. Dashboard - Welcome banner with gradient background - Productivity score card - Active projects - Tasks due today - Team activity feed - Upcoming deadlines - Recent files - Interactive charts (line, bar, donut) - Animated counters 5. Workspace & Projects - Workspace overview - Project cards with progress rings - Member avatars - Project filtering and sorting - Create project modal 6. Kanban Board - Columns: Backlog, Todo, In Progress, Review, Done - Drag-and-drop task cards - Priority badges - Due dates - Assignees - Subtasks - Attachment indicators - Smooth card lift animation while dragging 7. Task Details Drawer / Modal - Title, description, checklist - Comments thread - Emoji reactions - File attachments - Activity timeline - Mention users - Status and priority selectors 8. Team Management - Invite members - Role management (Owner, Admin, Member) - Permissions table - Member activity stats 9. File Management - Grid and list view - Upload progress animation - File preview cards - Drag-and-drop upload area 10. Notifications - Real-time notification panel - Unread badges - Mention alerts - Task updates - File upload alerts 11. Analytics Page - Team productivity - Task completion trends - Workload distribution - Project health - Interactive filters 12. Profile & Settings - Personal info - Security - Notifications - Appearance - Workspace preferences - Connected accounts Add premium micro-interactions and animations: - Fade-up on scroll - Staggered card entrance - Parallax floating elements - Hover glow effects - Magnetic buttons - Ripple click effects - Skeleton loading states - Animated progress bars - Smooth page transitions - Notification slide-ins - Sidebar morph animation - Chart drawing animation - Lottie-style loading screen with rotating SyncSpace logo Use realistic dummy data throughout the UI: - Team names - Project names - Comments - Deadlines - File names - Notifications The design must feel production-ready, startup-quality, and portfolio-worthy, with exceptional attention to spacing, hierarchy, responsiveness, and visual delight. Generate all pages and components with consistent design language and smooth interactive behavior.
